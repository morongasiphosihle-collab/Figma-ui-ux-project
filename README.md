🏥 CUT Campus Clinic Booking System

Project Overview

The CUT Campus Clinic Booking System is a mobile-first UI/UX design project created as part of the GUD226C Design Studio.

The project addresses a common challenge experienced by Central University of Technology students: difficulty finding available clinic appointments and being turned away because the clinic is fully booked.

The goal is to design a simple, accessible and user-friendly appointment booking experience that helps students view appointment options and complete a booking journey.

Project Type: UI/UX Design & Interactive Prototype
Design Tool: Figma
Course: GUD226C Design Studio
Platform: Mobile-first, with responsive desktop designs

🎯 Problem Statement

CUT students experience frustration when attempting to book clinic appointments, particularly when they discover that the clinic is fully booked.

This project explores how a digital booking interface could make appointment availability easier to understand and the booking process more convenient.

👤 Target Users

The primary target users are CUT students who need to access campus healthcare services.

The design considers:

- Students with busy academic schedules.
- Users who need convenient appointment booking.
- Users who require clear and readable interfaces.
- Students accessing the service through mobile devices.

✨ Key Features

- Clinic dashboard.
- Appointment booking interface.
- Clinic service selection.
- Appointment date and time selection.
- Booking review.
- Booking confirmation.
- No-appointment-available feedback.
- Responsive desktop and mobile interfaces.

🎨 Design Process

The project followed an eight-stage design process:

1. User Research: Developed a user persona and usage scenario.
2. Task Analysis: Identified user goals and created a Hierarchical Task Analysis (HTA).
3. Ideation: Explored three interface concepts and selected a clinic dashboard.
4. Wireframing: Created low-fidelity wireframes for the main booking journey.
5. Visual Design: Developed a consistent visual style using colour, typography and reusable components.
6. Responsive Design: Adapted three important screens for different screen sizes.
7. Mobile UX: Improved button sizes, spacing, readability and navigation.
8. Evaluation: Conducted usability testing and implemented improvements based on feedback.
